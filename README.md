# Simple Calculator Script + GUI

Python/Kivy calculator implementation for Jama feature `SDD-FEAT-1`.

## Included approved requirements

- `SDD-REQ-1`: addition
- `SDD-REQ-2`: subtraction
- `SDD-REQ-3`: division
- `SDD-REQ-5`: ten number buttons from 9 to 0
- `SDD-REQ-6`: calculate button in the bottom right
- `SDD-REQ-7`: purple calculate button
- `SDD-REQ-8`: result display in the top third of the UI
- `SDD-REQ-9`: operation buttons below the display
- `SDD-REQ-10`: Python code base
- `SDD-REQ-11`: Kivy UI
- `SDD-REQ-12`: clear button clears the display

`SDD-REQ-4` multiplication and `SDD-REQ-13` decimal point are not implemented.

## Run

```powershell
python -m pip install -r requirements.txt
python main.py
```
